# Security

Please report vulnerabilities privately to **contact@meerko.ai**, not in a public issue. Include what you found, how to
reproduce it and what it affects. We'll reply within a few working days, keep you posted while we fix it, and credit you
if you'd like.

This covers this repository and Meerko Cloud (meerko.ai and api.meerko.ai). Please don't access other people's data, send
email through other people's mailboxes, or degrade the service while testing.
