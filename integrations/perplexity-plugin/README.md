# Meerko plugin for Perplexity

Generated by `pnpm perplexity-plugin` from `packages/mcp/src/workflows.ts`: edit that, not these files.

- `plugin.json`: the plugin's name and description.
- `mcp.json`: Meerko's MCP server (https://api.meerko.ai/mcp), signed in with OAuth.
- `skills/`: find leads, find my first customers, write a sequence, triage replies, pipeline, the same workflows as the MCP prompts.

Install it from https://meerko.ai/perplexity: download the zip and upload it under Plugins → Add custom → Upload plugin or skill,
or choose Import plugin from GitHub and paste this folder's URL. Then connect Meerko on the plugin's page and sign in.
